## 🚀 Sobre mí

Soy **Aimar Esqueta Albert**, desarrollador con formación en **Desarrollo de Aplicaciones Multiplataforma (DAM)** y una orientación cada vez más fuerte hacia el **desarrollo Full-Stack, la automatización de procesos, los datos y la IA aplicada**.

Me gusta crear soluciones que no se quedan solo en “hacer una app”, sino que realmente ayudan a organizar mejor el trabajo, reducir tareas manuales, visualizar información y tomar mejores decisiones.

Actualmente estoy centrado en construir proyectos propios y profesionales alrededor de:

- Desarrollo web y móvil.
- Automatización de procesos empresariales.
- Herramientas internas a medida.
- Dashboards y análisis de datos.
- Integración de IA en productos reales.
- Optimización de flujos de trabajo con visión técnica y de negocio.

Mi forma de trabajar parte de una idea clara:

> Primero entender el proceso. Luego organizarlo. Después automatizarlo o construir la herramienta adecuada.

## 🧭 Mi filosofía como desarrollador

No me interesa construir tecnología por construirla.

Me interesa entender un problema, analizar cómo funciona, simplificarlo y después crear una solución que sea clara, mantenible y útil.

```txt
Entender → Organizar → Optimizar → Automatizar → Medir → Mejorar
```

Creo que las mejores soluciones nacen cuando se combina:

- Buen análisis del problema.
- Código limpio.
- Diseño sencillo.
- Datos bien estructurados.
- Automatización inteligente.
- Visión de negocio.
